# Pixel Space Shooter (KO9MA LAB Demo)

외부 이미지·오디오 파일 없이 **단일 `index.html` 파일 1개**로 동작하는 8비트 레트로 우주 슈팅 게임입니다.  
바이브 코딩 입문자도 코드를 바로 읽고 수정하거나 GitHub Pages로 1분 만에 배포할 수 있도록 단순하고 깔끔하게 구성했습니다.

- **라이브 플레이**: https://ko9ma7.github.io/retro-pixel-shooter/
- **주요 기술**: HTML5 `<canvas>` 2D 픽셀 배열 렌더링, Web Audio API 칩튠 사운드, 모바일 터치 패드(`touch-action: none`), `localStorage` 최고 점수 저장
